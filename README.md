A program that draws, pixel by pixel using only the Python standard library, a travel poster for **Nerevia** — a place that does not exist: a white cliff town and a lighthouse on a headland above a golden lagoon at dusk, the low sun on the horizon, two sailboats on the water, and the island's name set large across the sky.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, well under the 1 MiB cap). No network, no randomness, no dependencies: two runs produce a byte-identical image.

## The place

Nerevia is an invented island in a lagoon that holds the light of the day long after the sun has gone down. Its one landmark is the lighthouse on the headland, whose beam sweeps the dusk while the cliff town below lights its windows; the promise of a stay there is a slow evening on the water, watching the sun set twice — once in the sky, once in the lagoon.
